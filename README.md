# Curio By Dabby

Official website for Curio By Dabby – a premium lifestyle, fashion, beauty and intelligent gifting brand.

**Tagline:** More Than Gifts. More Than Shopping.

## Official Colour System
- Deep Plum: `#54263F`
- Champagne Beige: `#D8BFA3`
- Warm Ivory: `#FAF6F0`
- Soft Taupe: `#A89483`
- Charcoal: `#292526`

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion (coming next)
- Ready for AI integration

## Getting Started (for developers)
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
